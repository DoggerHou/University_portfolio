# Лабораторная работа 1 — Генерирование случайных величин и проверка гипотезы

Дисциплина: **Компьютерное моделирование**  
Цель работы — научиться генерировать выборки из заданных распределений, оценивать их параметры по выборке и проверять, насколько сгенерированные данные согласуются с теоретическим законом распределения по критерию Пирсона (χ²).

В работе рассматриваются три распределения:

- распределение Пуассона;
- показательное (экспоненциальное) распределение;
- равномерное распределение на отрезке.

---

## Задание (в общих чертах)

Для каждого распределения нужно:

1. Сгенерировать выборку псевдослучайных чисел заданного объёма.
2. Оценить параметры распределения по выборке (метод моментов / через выборочное среднее).
3. Построить группированную выборку: интервалы, частоты, середины интервалов.
4. По выбранному теоретическому распределению посчитать **ожидаемые частоты**.
5. Построить гистограмму (и, при необходимости, полигон частот).
6. Проверить гипотезу  
   > H₀: выборка подчиняется заданному закону распределения  
   по **критерию согласия χ²** при уровне значимости `α = 0.05`:
   - посчитать наблюдаемое χ²;
   - найти критическое значение χ² по числу степеней свободы;
   - сделать вывод: гипотеза принимается или отвергается.

---

## Структура и что делает каждый скрипт

### 1. `poisson.py` — распределение Пуассона

- Генерирует выборку из распределения Пуассона с параметром `lambda = 4` через накопление значений распределения с использованием равномерной случайной величины `U ~ U(0, 1)`. 
- Считает оценку параметра `lambda` как выборочное среднее:
  `lambda_hat = (Σ i * n_i) / N`.
- По `lambda_hat` вычисляет **теоретические частоты** для каждого возможного значения случайной величины.
- Собирает таблицу с колонками: значение `i`, наблюдаемая частота `n_i`, теоретическая частота `n'_i`, разность, квадрат разности и вклад в χ².
- Объединяет редкие события с маленькими частотами, пока в каждом классе ожидаемая частота > 5 (требование критерия Пирсона).
- Считает:
  - наблюдаемое χ² — как сумму по всем классам,
  - критическое χ² по распределению `chi2` с числом степеней свободы `k - 1 - 1` (минус один параметр λ).
- Печатает вывод о принятии / отклонении гипотезы и строит столбчатую диаграмму полученных частот.

### 2. `exponential.py` — показательное распределение

- Генерирует выборку объёма `N` из показательного распределения с параметром `lambda = 0.6` по формуле обратной функции распределения:
  `X = -ln(1 - U) / lambda`. 
- Делит ось на `k = 1 + floor(log2 N)` интервалов, считает:
  - границы интервалов,
  - частоты попадания значений в каждый интервал,
  - середины интервалов.
- Оценивает параметр `lambda` как `lambda_hat = 1 / x̄`, где `x̄` — выборочное среднее (из сгруппированных данных).
- Для каждого интервала считает **теоретическую частоту**:
  `n'_i = N * (F(right_i) - F(left_i))`, где `F(x)` — функция распределения экспоненциального закона с параметром `lambda_hat`.
- Формирует таблицу для χ², объединяет интервалы с малыми ожидаемыми частотами, считает наблюдаемое и критическое χ² и выводит решение по гипотезе.
- Визуализация: гистограмма выборки (плотность) для наглядного сравнения с экспоненциальной кривой.

### 3. `uniform.py` — равномерное распределение

- Генерирует выборку из равномерного распределения на отрезке `[a, b]`, здесь `a = 0`, `b = 100`:  
  `X = a + (b - a) * U`, `U ~ U(0, 1)`. 
- Строит `k = ceil(1 + log2 N)` интервалов (формула Стерджесса), для каждого считает:
  - фактическую частоту,
  - середину интервала.
- По сгруппированным данным находит:
  - выборочное среднее `x̄`,
  - выборочную дисперсию `S²`,
  - выборочное стандартное отклонение `S`.
- Использует известные формулы для равномерного распределения,
  чтобы оценить границы `a_hat` и `b_hat`:
  - `a_hat = x̄ - sqrt(3 * S²)`,
  - `b_hat = x̄ + sqrt(3 * S²)`.
- По `a_hat` и `b_hat` считает **теоретические частоты**:
  `n'_i = N * f(x) * длина_интервала`, где `f(x) = 1 / (b_hat - a_hat)`.
- Формирует таблицу для χ², считает наблюдаемое и критическое χ² (степени свободы с учётом двух оцениваемых параметров), делает вывод о гипотезе.
- Строит гистограмму выборки.

## Используемый стек

- Язык: `Python 3`.
- Библиотеки:
  - `numpy`, `math` — вычисления;
  - `scipy.stats.chi2` — критические значения χ²;
  - `prettytable` — красивый вывод таблиц с частотами и промежуточными расчётами;
  - `matplotlib` — гистограммы и графики.
