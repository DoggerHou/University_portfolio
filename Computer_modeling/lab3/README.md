### Лабораторная 3. Вычисление интеграла методом Монте-Карло

**Идея.** Посчитать определённый интеграл численным методом Монте-Карло: вместо аналитики — много случайных точек под графиком и усреднение результата. :contentReference[oaicite:0]{index=0}  

**Задание**

- Выбран интеграл вида  
  ∫ f(x) dx на отрезке `[a, b]`, где  
  `f(x) = 3x² + 6x − 4`, `a = 0`, `b = 10`.  
  Для него известно точное значение `I_exact = 1260`.
- Нужно:
  - сгенерировать `n` равномерных случайных точек `x_i` на `[a, b]`;
  - посчитать `f(x_i)` и по ним оценить интеграл;
  - сравнить оценку с точным значением;
  - построить доверительный интервал для полученной оценки.

**Что сделано в `main.py`**

- Реализованы две базовые процедуры:
  - `f(x)` — подынтегральная функция `3*x**2 + 6*x - 4`;
  - `uniform(a, b)` — генерация равномерного числа на `[a, b]` по формуле  
    `a + (b - a) * random.random()`.
- Задаются параметры:
  - `a = 0`, `b = 10`;
  - `n = 1_000_000` испытаний;
  - доверительная вероятность `alpha = 0.95`.
- Основной цикл:
  - генерируется `n` точек `x_i` на `[a, b]`;
  - для каждой считается `f(x_i)`, первые 100 испытаний выводятся в консоль;
  - оценка интеграла вычисляется как  
    `I_est = (b - a) * (1/n) * Σ f(x_i)`.
- После этого программа:
  - печатает оценку `I_est`, точное значение `I_exact` и модуль ошибки;
  - по `scipy.stats.t.ppf` находит t-критическое значение для уровня 0.95;
  - по выборке строит доверительный интервал для интеграла вида  
    `I_est ± t * S / sqrt(n)`, где `S` — выборочное среднеквадратическое отклонение;
  - проверяет, попадает ли оценка в найденный интервал, и выводит текстовый вывод.

Лаба демонстрирует базовую схему метода Монте-Карло для интегралов: генерация равномерных точек, усреднение значений функции, оценка погрешности и построение доверительного интервала для результата.
