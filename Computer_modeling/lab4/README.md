### Лабораторная 4. Задача коммивояжёра и генетический алгоритм

**Идея.** Решить задачу коммивояжёра (TSP) с помощью генетического алгоритма как примера метаэвристики для NP-трудных задач комбинаторной оптимизации.

**Задание**

- Задаётся классическая постановка TSP: есть набор городов и расстояния между всеми парами, нужно найти цикл минимальной длины, проходящий через каждый город ровно один раз и возвращающийся в начальный.
- Требуется выбрать один из метаэвристических алгоритмов (генетический, эволюционный, алгоритм муравьиной колонии) и реализовать его для TSP. В этой работе реализован **генетический алгоритм**. 
- Численные эксперименты проводятся на тестах из .txt файлах, с последующим сравнением качества маршрутов и влияния параметров алгоритма.

**Что сделано**

- Входные данные: файл `50.txt` со списком городов (номер + координаты). Для каждого города создаётся объект `City` с методами для доступа к координатам и номеру.
- Вспомогательные функции:
  - `get_distance(city1, city2)` — евклидово расстояние между двумя городами по координатам.
  - `get_path_distance(route)` — длина тура (с возвратом в исходный город) для заданного маршрута.
  - `double_crossover(parent1, parent2)` — двухточечное скрещивание маршрутов-перестановок: сначала берётся часть пути от одного родителя, затем заполняются «дыры» городами из другого без повторов. Даёт двух детей.   
  - `mutate(child1, child2)` — простая мутация: выбираются две позиции и города на них меняются местами (swap-мутация), причём сразу у обоих потомков.   

- Инициализация популяции:
  - константы: `GENERATION_SIZE = 150`, `MUTATION_RATE = 0.65`;
  - создаётся `len(cities)` случайных особей: для каждого индивида список городов перемешивается (`random.shuffle`), получается случайный маршрут.

- Основной цикл ГА:
  - на каждой итерации случайно выбираются два разных родителя из популяции;
  - по ним строятся два потомка через `double_crossover`;
  - с вероятностью `MUTATION_RATE` к потомкам применяется `mutate`;
  - потомки добавляются к популяции;
  - популяция сортируется по `get_path_distance` (короче маршрут — лучше фитнес);
  - две худшие особи отбрасываются, чтобы размер популяции оставался постоянным. 

- По завершении всех поколений:
  - лучшим решением считается первый маршрут в отсортированной популяции (`population[0]`);
  - в консоль выводится длина лучшего найденного тура.
