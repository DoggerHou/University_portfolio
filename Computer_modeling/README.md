# Компьютерное моделирование

Здесь собраны лабораторные работы по дисциплине **«Компьютерное моделирование»**.

## Содержание

- [Лабораторная 1. Генерация случайных величин и критерий χ²](./lab1/README.md) — генерация выборок из равномерного, экспоненциального и пуассоновского распределений, оценка параметров по выборке, построение гистограмм и проверка гипотезы о виде распределения с помощью критерия согласия χ².

- [Лабораторная 2. Имитация СМО «кофейня с одной кассой»](./lab2/README.md) — событийная имитационная модель одноканальной системы массового обслуживания с нестационарным пуассоновским потоком, экспоненциальным обслуживанием и очередью FIFO. Подсчёт средних времен ожидания и пребывания в системе, средней длины очереди, коэффициента занятости кассы и задержки закрытия.

- [Лабораторная 3. Метод Монте-Карло для интеграла](./lab3/README.md) — численное вычисление определённого интеграла методом Монте-Карло: генерация равномерных точек на отрезке, оценка интеграла по выборочному среднему, сравнение с точным значением и построение доверительного интервала.

- [Лабораторная 4. Задача коммивояжёра и генетический алгоритм](./lab4/README.md) — решение задачи коммивояжёра по координатам городов с помощью генетического алгоритма: случайная инициализация популяции маршрутов, двухточечное скрещивание, swap-мутация и отбор по длине пути, получение приближённо оптимального тура.

## Темы, которые покрываются

- Генерация псевдослучайных чисел и моделирование распределений (равномерное, экспоненциальное, пуассоновское).  
- Проверка статистических гипотез: критерий согласия χ², работа с сгруппированными данными.  
- Имитационное моделирование систем массового обслуживания: событийный подход, журнал событий, оценка эксплуатационных характеристик.  
- Метод Монте-Карло: стохастическое интегрирование, оценка погрешности и доверительные интервалы.  
- Комбинаторная оптимизация и метаэвристики: генетический алгоритм для задачи коммивояжёра (представление решений, кроссовер, мутация, отбор).

## Стек и инструменты

- Язык: **Python 3**.  
- Библиотеки: `random`, `math`, `numpy`, `scipy`, `matplotlib`, `prettytable`.  
- Среда: любой интерпретатор / IDE для Python (VS Code, PyCharm и т.п.), запуск из консоли.
