# Лабораторная работа 6 — рисование фигур

## Задание
Продолжение Лабораторной работы 4.1.
  Необходимо сделать простое GUI-приложение на Windows Forms, где на рабочем поле можно создавать геометрические фигуры (круг, квадрат, треугольник), менять их цвет, размер и положение. Фигуры должны храниться в собственном хранилище, уметь сами себя рисовать и сами решать, попали ли по ним мышью. Выделенные фигуры можно двигать с клавиатуры, масштабировать, перекрашивать и удалять, в том числе выбирать несколько одновременно с зажатым `Ctrl`.

## Что сделано

- **Модель фигур**  
  Введён базовый класс `Model` с общими полями (координата центра, цвет, размер, признак “выделен”) и методами для отрисовки, проверки попадания мыши, изменения размера и перемещения с учётом границ `PictureBox`. От него наследуются `CCircle`, `CSquare` и `Triangle`, которые по-своему рисуют фигуру и по-своему проверяют, попала ли точка клика внутрь (круг — через расстояние, квадрат — через диапазоны по X/Y, треугольник — через сравнение площадей подфигур).   

- **Хранилище объектов**  
  Класс `Storage` хранит список фигур (`List<Model>`), добавляет новые, снимает выделение со старых, если создан новый объект, и удаляет все выделенные по запросу. При добавлении сначала проверяется, не кликнули ли по уже существующей фигуре (через её `isPicked`) — в этом случае просто переключается выделение, а новая фигура не создаётся.   

- **Интерфейс и управление**  
  Главная форма содержит рабочее поле (`PictureBox`) и панель кнопок для выбора цвета и типа фигуры. Клик по полю создаёт новую фигуру выбранного типа и цвета или меняет выделение существующей. С клавиатуры можно:
  - `Ctrl` — включить режим мультивыделения,
  - стрелки — двигать все выделенные фигуры,
  - `+` / `-` на NumPad — увеличивать/уменьшать размер выделенных фигур,
  - `Delete` — удалять выделенные.  
  Цвет можно задать как готовыми цветными кнопками, так и через `ColorDialog` — выбранный цвет сразу применяется ко всем выделенным объектам. Отрисовка идёт через событие `Paint`, где форма просто проходит по хранилищу и вызывает `OnPaint` у каждой фигуры.   

В итоге получается доморощенный “пейнт”, который показывает работу с наследованием, собственным контейнером объектов, событиями WinForms и отрисовкой фигур по данным из модели.
