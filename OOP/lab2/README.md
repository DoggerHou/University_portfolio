# Лабораторная работа 1 — кнопки и формы

## Задание
Сделать простое GUI-приложение на Windows Forms, в котором на одной или нескольких формах используется не меньше 15 **разных** стандартных элементов управления. Нужно показать работу основных событий – мышь, клавиатура, выбор пунктов меню/элементов, изменение размера окна, перерисовка, таймер — и уметь в рантайме менять свойства контролов. Отдельно требовалось продемонстрировать динамическое создание и удаление элементов интерфейса по действиям пользователя.

## Что сделано
Собрано небольшое демо-приложение из главной формы и нескольких дополнительных окон:

- **Структура приложения**
  - главная форма с навигацией по остальным формам;
  - несколько отдельных окон, каждое под свой набор контролов и событий;

- **Элементы управления**
  - кнопки, текстовые поля, списки, чекбоксы и радио-кнопки;
  - вкладки, прогрессбар и трекбар;
  - ссылочный label, выбор даты, картинки и т.п.;

- **Обработка событий**
  - движение и клики мышью;
  - нажатия клавиш, переключение вкладок, работа со списками;

- **Динамика и поведение**
  - свойства элементов (текст, видимость, цвет, значения) меняются на лету;
  - по клику в нужных местах создаются новые элементы интерфейса (например – смешные картинки);
