# Лабораторная работа 4 — круги на форме

## Задание

Сделать простое GUI-приложение, в котором на форме по клику мышью создаются объекты класса `CCircle` с фиксированным радиусом и координатами точки нажатия. Круги нужно хранить в отдельном хранилище, а в обработчике `Paint` отрисовывать все объекты из этого хранилища. Отдельно по заданию требуется реализовать выделение кругов: новый круг становится выделенным, по клику левой кнопкой по существующему кругу он тоже выделяется, по `Delete` все выделенные удаляются, а при удержании `Ctrl` можно выделять несколько объектов. Логика инкапсуляции важна: круг сам решает, попала ли по нему мышь и как себя рисовать.

## Что сделано

- **Класс CCircle**  
  Круг хранит свои координаты и радиус, сам решает, попала ли в него мышь, и сам себя рисует. За счёт этого главное окно не знает ничего о внутренней структуре объекта — только вызывает методы.

- **Собственное хранилище объектов**  
  Небольшой класс-контейнер управляет списком кругов: добавляет новые, переключает выделение, отдаёт элементы для отрисовки и удаляет нужные по запросу. По сути — упрощённый аналог коллекции, реализованный вручную.

- **Работа с GUI-событиями**  
  Форма реагирует на клики по `PictureBox` (создание и выделение кругов) и на `KeyDown` (`Ctrl` — мультивыделение, `Delete` — удаление выделенных). После каждого действия перерисовывается сцена и обновляется счётчик объектов.

- **Отрисовка через Paint-событие**  
  Все круги отрисовываются в `Paint`, причём выделенные отображаются другим стилем. Объекты рисуют себя самостоятельно — форма лишь вызывает правильный метод у каждого круга.
