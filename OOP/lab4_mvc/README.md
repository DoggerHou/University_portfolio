# Лабораторная работа 4 — MVC

## Задание

Сделать небольшое WinForms-приложение в стиле MVC: отдельная модель хранит три целых значения `A`, `B` и `C` и поддерживает инвариант `A ≤ B ≤ C`. Представление (форма) может менять эти значения разными способами (через текстовые поля, слайдеры, спинбоксы), а контроллерская логика должна ходить только в модель, не лезть напрямую во внутренние поля. Модель при изменении состояния должна оповещать подписчиков (view) и уметь сохранять/загружать свои значения из файла.

## Что сделано

- **Модель**  
  Класс `Model` хранит три значения `A`, `B`, `C`, следит за условием `A ≤ B ≤ C` и после каждого изменения вызывает событие `observers`. Для каждого параметра есть свой `setValue_*`, где логика правит остальные значения так, чтобы инвариант не нарушался. Модель умеет читать и писать текущее состояние в текстовый файл `Values.txt`.

- **Представление и контроллер**  
  `Form1` содержит три набора виджетов (`TextBox`, `TrackBar`, `NumericUpDown`) для `A`, `B` и `C`. Любое изменение в интерфейсе (скролл трекбара, изменение числа в `NumericUpDown`, Enter в текстовом поле) уходит в соответствующий `setValue_*` модели. На событие `observers` форма подписана методом `UpdateFromModel`, который обновляет все элементы сразу, чтобы все три способа ввода всегда показывали актуальные значения. При загрузке формы модель подтягивает данные из файла, при закрытии — сохраняет обратно. В итоге это компактный пример разнесения ролей: модель знает только про данные и правила, а форма — только про визуал и взаимодействие с пользователем.
