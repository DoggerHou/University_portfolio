# Лабораторная работа 7 — группы фигур и паттерны

## Задание

Сделать приложение на Windows Forms, в котором на рабочем поле можно создавать фигуры (круг, квадрат, треугольник), выделять их, менять цвет, размер и положение, а также объединять несколько фигур в одну группу и работать с ней как с единым объектом. Фигуры и группы должны храниться в собственном хранилище, уметь сами себя рисовать, сами решать, попала ли по ним мышь, **и уметь сохраняться/загружаться из файла так, чтобы корректно восстанавливалась иерархия “группа в группе”**. Для этого предлагается использовать паттерны **Composite** (группа фигур как объект) и **Factory Method** (создание объектов по типу при загрузке.)

## Что сделано

- **Иерархия фигур**  
  Введён базовый класс `Model` с общими полями (центр, размер, цвет, признак выделения, границы `PictureBox`) и методами для отрисовки, хита по мыши, движения, изменения размера и сохранения/загрузки. От него наследуются `Circle`, `Square` и `Triangle`, которые по-разному рисуют себя и проверяют попадание мыши (круг — через радиус, квадрат — через диапазоны по X/Y, треугольник — через сравнение площадей).

- **Паттерн Composite: класс `Group`**  
  Класс `Group` тоже наследуется от `Model`, но внутри хранит список других `Model` (в том числе вложенных групп). Он рисует все дочерние фигуры и поверх них — рамку группы, умеет двигать, масштабировать и перекрашивать сразу весь набор, а также сохранять/загружать своё содержимое. При сохранении записывается тип объекта и структура вложенности, при загрузке рекурсивно восстанавливается та же самая иерархия, включая группы внутри групп.

- **Паттерн Factory Method: `ModelFactory` / `MyObjectsFactory`**  
  Абстрактная фабрика `ModelFactory` и реализация `MyObjectsFactory` создают нужный тип объекта по строковому коду (`"Circle"`, `"Square"`, `"Triangle"`, `"Group"`). При загрузке из файла хранилище читает тип, отдаёт его в фабрику и получает готовый объект, который затем сам дочитывает свои параметры. Для групп это означает создание объекта `Group` и рекурсивное восстановление всех его дочерних фигур.

- **Хранилище и сериализация**  
  Класс `Storage` держит список `List<Model>`, добавляет новые объекты, удаляет выделенные, группирует/разгруппировывает выбранные фигуры и сохраняет всё в текстовый файл. Формат хранения позволяет не только записать параметры фигур, но и восстановить структуру вложенности: при чтении файл разбирается построчно, через фабрику создаются нужные объекты, а для групп рекурсивно собирается дерево “группа в группе”.

- **GUI и управление**  
  Главная форма содержит `PictureBox` как рабочее поле, панель выбора цвета и панель выбора типа фигуры.  
  Управление:
  - клик по полю — создание новой фигуры выбранного типа и цвета или переключение выделения у существующей;
  - `Ctrl` — мультивыделение;
  - `Shift` — сгруппировать выделенные объекты;
  - `A` — разгруппировать выделенную группу;
  - стрелки — совместное движение всех выделенных фигур;
  - `+` / `-` (NumPad) — изменение размера выделенных фигур;
  - `Delete` — удаление выделенных;
  - кнопки цвета и `ColorDialog` — перекрашивание выделенных фигур.  
  При закрытии формы хранилище автоматически сохраняется в файл, при запуске — загружается обратно, восстанавливая группы и вложенные в них элементы.
