# Лабораторная работа 1 — кнопки и формы

## Задание
Сделать простое GUI-приложение на Windows Forms, в котором на одной или нескольких формах используется не меньше 15 **разных** стандартных элементов управления. Нужно показать работу основных событий — мышь, клавиатура, выбор пунктов меню/элементов, изменение размера окна, перерисовка, таймер — и уметь в рантайме менять свойства контролов. Отдельно требовалось продемонстрировать динамическое создание и удаление элементов интерфейса по действиям пользователя.

## Что сделано
Собрано небольшое демо-приложение из главной формы и нескольких дополнительных окон. На них используются кнопки, текстовые поля, списки, чекбоксы, радио-кнопки, вкладки, прогрессбар, трекбар, link-label, date-picker и несколько картинок. Обрабатываются события движения и кликов мышью, нажатий клавиш, переключения вкладок, кликов по прогрессбару и работе с элементами списков; часть контролов привязана к общим обработчикам, которые различают отправителя через `sender`. Свойства элементов меняются “на лету” (текст, видимость, цвет, значения), а в нужных местах по клику создаются новые элементы интерфейса (например, маленькие картинки под курсором). В сумме это покрывает требования преподавателя и демонстрирует базовую работу с формами, событиями и динамическими контролами — настолько, насколько имеет смысл для такой простой лабы.
