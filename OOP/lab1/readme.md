# Лабораторная работа 1 — кнопки и формы

## Задание
Сделать простое GUI-приложение на Windows Forms, в котором на одной или нескольких формах используется не меньше 15 разных стандартных элементов управления. Нужно показать работу основных событий — мышь, клавиатура, выбор пунктов меню/элементов, изменение размера окна, перерисовка, таймер — и уметь в рантайме менять свойства контролов. Отдельно требовалось продемонстрировать динамическое создание и удаление элементов интерфейса по действиям пользователя.

## Что сделано
Собрано небольшое демо-приложение из главной формы и нескольких дополнительных окон. На них используются кнопки, текстовые поля, списки, чекбоксы, радио-кнопки, вкладки, прогрессбар, трекбар, link-label, date-picker и т.д. Обрабатываются события движения и кликов мышью, нажатий клавиш, переключения вкладок, кликов по прогрессбару; часть контролов связаны общими обработчиками. Свойства элементов я меняю “на лету”, а по клику в нужных местах создаются новые элементы (например, картинки) прямо под курсором — этого достаточно, чтобы показать базовую работу с формами и событиями без лишней драмы вокруг такой простой лабы.
