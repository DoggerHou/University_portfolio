# ООП — Лабораторная работа 1: «Кнопки и формы»

## Цель работы

Освоить базовую технологию создания GUI-приложений:

- работа с формой, меню и стандартными элементами управления;
- настройка свойств объектов как в режиме дизайна (design time), так и во время выполнения (runtime);
- обработка событий мыши, клавиатуры и системных событий формы;
- динамическое создание и уничтожение элементов интерфейса по действиям пользователя.

## Постановка задачи (по условию работы)

Необходимо разработать простейшее desktop-приложение с графическим интерфейсом пользователя (GUI) в любой среде (например, Windows Forms / WPF / Qt и т.п.), которое:

- содержит **форму**, меню и несколько пунктов меню;
- использует **не менее 15 разных типов стандартных компонентов** (кнопки, текстовые поля, списки, чекбоксы, радио-кнопки, панели, закладки и т.д.);
- демонстрирует работу основных событий:
  - нажатие и перемещение мыши;
  - нажатие клавиш;
  - выбор пунктов меню;
  - перерисовка (событие `Paint`);
  - изменение размера окна (`Resize`);
  - работа таймера (задержки, периодические действия);
- показывает **взаимодействие объектов интерфейса**: при событии на одном контроле изменяется состояние другого;
- демонстрирует:
  - один обработчик, привязанный к нескольким событиям/объектам;
  - программный вызов обработчиков/событий (`PerformClick` или аналог);
- умеет **динамически создавать и уничтожать элементы интерфейса** (например, по клику мыши на форме создаётся новый контрол, который реагирует на свои события).

Главная идея: не сделать “полезное” приложение, а как можно шире потрогать разные типы компонент и их события.

## Краткое описание реализации

> Здесь опиши именно твою программу, без воды. Ниже пример структуры, ты подгоняешь под свой проект.

Приложение реализовано на **C# / Windows Forms** (подставь свой стек) и состоит из одной основной формы `MainForm`.

На форме находятся:

- **меню** с пунктами:
  - «Файл» → «Выход»;
  - «Вид» → включение/выключение отдельных панелей;
  - «Тест событий» → запуск демонстраций;
- **панель с управляющими элементами** (слева/сверху);
- **рабочая область** для демонстрации событий и динамического создания контролов.

Используются как минимум следующие компоненты (список нужно подогнать под твой реальный набор):

- `Button`
- `Label`
- `TextBox`
- `CheckBox`
- `RadioButton`
- `ComboBox`
- `ListBox`
- `GroupBox`
- `Panel`
- `TabControl`
- `TrackBar`
- `ProgressBar`
- `NumericUpDown`
- `Timer`
- `MenuStrip` / `ToolStrip`

Для нескольких объектов один и тот же обработчик событий используется повторно. Например, три разные кнопки используют один обработчик `OnColorButtonClick`, который по отправителю (`sender`) определяет, какой цвет применить.

## Обработка событий

В приложении продемонстрированы следующие группы событий:

### События мыши

- `MouseMove` по форме — в статусной строке/лейбле показываются текущие координаты мыши.
- `MouseDown` / `MouseUp` на отдельных контролах — меняется цвет/текст/состояние элементов.
- `Click` по рабочей области — создаётся новый динамический контрол (например, кнопка) в точке клика.

### События клавиатуры

- Обработка `KeyDown` / `KeyUp` на форме:
  - при нажатии определённых клавиш (например, `R`, `G`, `B`) меняется цвет фона;
  - при `Esc` — сброс каких-то настроек или закрытие формы (по заданию/твоему вкусу).

### Событие перерисовки (`Paint`)

- В обработчике `Paint` демонстрируется, как форма самостоятельно перерисовывает своё содержимое:
  - рисуются простые фигуры/надписи;
  - визуально отражается состояние некоторых контролов (например, количество динамически созданных элементов).

Важно: `Paint` не вызывается вручную «каждый раз», а срабатывает по запросу системы/`Invalidate()`.

### Изменение размера окна (`Resize`)

- В обработчике `Resize`:
  - перестраивается расположение контролов (докинг, анкоринг);
  - возможно, меняется текст/цвет, если форма слишком маленькая/большая.

### Таймер

- Таймер используется для:
  - периодического обновления какого-то элемента (например, бегущая строка, анимация цвета, прогрессбар);
  - демонстрации задержек без блокировки UI.

## Динамическое создание и удаление элементов интерфейса

По клику мыши на форме:

- создаётся новый объект (например, `Button` или `Label`) в координатах клика;
- ему присваивается текст/номер (напр. `Button #5`);
- к нему привязывается обработчик `Click`, который, например, показывает сообщение или меняет цвет самого объекта.

Элементы также могут удаляться:

- по дополнительному событию (например, `RightClick` по элементу или отдельная кнопка «Удалить динамические элементы»);
- при этом освобождаются ссылки, и элемент перестаёт отображаться.

## Управление свойствами объектов (design time и runtime)

Для каждого важного компонента показаны:

- **Главные свойства** (например, `Text`, `Checked`, `SelectedIndex`, `Value`, `Enabled`, `Visible`, `BackColor`, `ForeColor`);
- Изменение этих свойств:
  - в дизайнере (до запуска);
  - из кода при обработке событий (во время работы приложения).

Например:

- `TextBox` — изменение текста по кнопке;
- `CheckBox` — управление доступностью других контролов;
- `TrackBar` — управление значением `ProgressBar` или размером какого-то элемента;
- `ComboBox` — выбор темы/цветовой схемы.
