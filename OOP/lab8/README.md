# Лабораторная работа 8 — дерево объектов, подписка

## Задание

Расширить приложение из прошлых лабораторных: на форме по-прежнему можно создавать фигуры (круг, квадрат, треугольник), группировать их и сохранять/загружать состояние из файла, но теперь нужно:

- отображать структуру хранилища фигур (включая группы и вложенные группы) в виде дерева;
- синхронизировать дерево и форму: в дереве можно выделять объекты, а любые изменения в хранилище должны обновлять дерево;
- добавить режим «липких» объектов: если фигура помечена как sticky, то при её движении за ней должны двигаться все объекты, с которыми она соприкасается;
- для реализации использовать паттерн observer

## Что сделано

- **Базовая модель и группы фигур**  
  Как и в прошлой работе, есть абстрактный класс `Model` (центр, размер, цвет, выделение, границы `PictureBox`) и наследники `Circle`, `Square`, `Triangle`, которые по-разному рисуются и проверяют попадание мыши. Класс `Group` тоже наследуется от `Model`, хранит список фигур и умеет работать с вложенными группами: отрисовывает всех потомков, считает рамку по их границам и двигает/масштабирует сразу всё содержимое группы.

- **Observer + дерево объектов**  
  И `Storage`, и сами модели наследуются от `Observerable`, который хранит список наблюдателей и рассылает уведомления. Наблюдатель `TreeObserver` строит `TreeNode` с зеркалом структуры хранилища: отдельные фигуры и группы превращаются в узлы дерева, выделение в интерфейсе отражается галочками в `TreeView`. При любых изменениях (добавление, удаление, группировка, загрузка из файла) хранилище оповещает наблюдателя, дерево автоматически пересобирается, а обратная связь идёт через обработчик `AfterCheck`.

- **Observer для «липких» объектов**  
  У фигур есть флаг `sticky` и метод `isSticked`, который проверяет, соприкасаются ли два объекта. Наблюдатель `StickyObserver` подписывается на движение отмеченных фигур: когда такая фигура двигается, он проходит по хранилищу и сдвигает все объекты, которые «прилипли». В итоге получается простой, но наглядный пример, как с помощью Observer связать несколько объектов, не завязывая их жёстко друг на друга.

- **Хранилище, фабрика и работа с файлами**  
  Класс `Storage` управляет списком `List<Model>`: добавляет объекты, удаляет выделенные, группирует/разгруппировывает, сохраняет и загружает всё дерево. Для сериализации используется текстовый формат: каждый объект пишет свой тип и параметры, группы дополнительно хранят количество вложенных элементов. При чтении используется `ModelFactory` / `MyObjectsFactory`, которые по строковому коду создают нужный тип (`Circle`, `Square`, `Triangle`, `Group`) и передают ему Stream для восстановления состояния.

- **Интерфейс и управление**  
  Интерфейс — это рабочее поле (`PictureBox`) плюс три панели: выбор фигуры, выбор цвета и `TreeView` со структурой хранилища. Клик по полю создаёт фигуру выбранного типа и цвета или переключает выделение существующей. С клавиатуры можно двигать выделенные объекты стрелками, увеличивать/уменьшать (`+` / `-`), удалять (`Delete`), группировать (`Shift`), разгруппировывать (`A`) и включать «липкий» режим (`Alt`). Цвет задаётся кнопками-образцами или через `ColorDialog`, изменения применяются к выбранным объектам. При старте данные загружаются из файла, при закрытии — сохраняются.
