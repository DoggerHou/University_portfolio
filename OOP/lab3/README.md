# Лабораторная работа 3 — хранилище

## Задание

Нужно написать консольное приложение с собственным классом хранилища объектов разных типов, у которых есть общий предок. Хранилище должно вести себя как массив или список: уметь добавлять объекты, удалять (с уничтожением и без), получать объект по индексу и по очереди проходить по всем элементам. Основная программа должна в случайном порядке создавать объекты, кладать их в хранилище, иногда их использовать (вызывать методы), иногда удалять, запускать циклы на 100/1000/10000 действий и замерять время работы. Использовать STL-контейнеры нельзя, хранилище нужно реализовать самостоятельно.

## Что сделано

- **Иерархия объектов**  
  Определён абстрактный базовый класс `BaseClass` с виртуальным деструктором и чисто виртуальной функцией `ShowName()`. От него наследуются три типа объектов:
  - `People` — человек с именем, ростом и весом, берущимися случайно из массива имён; есть методы `ShowParam()` и `SetPeopleParam(...)`.
  - `Metal` — металл с именем из файла `Metals.txt`, реализует `ShowName()`.
  - `Matrix` — случайная квадратная матрица (две входные и одна результирующая) с операциями сложения, умножения и вывода результата. :contentReference[oaicite:2]{index=2}

- **Класс хранилища**  
  Класс `Storage` хранит массив указателей `BaseClass**` фиксированного начального размера и при переполнении увеличивает его вдвое (`Resize()`). Есть методы:
  - `SetObject(index, BaseClass*)` — поместить объект по индексу (со заменой и удалением старого, если он был);
  - `GetObjectClass(index)` — получить указатель на объект;
  - `DeleteObject(index)` — удалить объект и освободить память;
  - `GetSize()` — вернуть текущий размер массива. Свободные слоты помечаются как `nullptr`. 

- **Основная программа**  
  В `main` из файлов `Metals.txt` и `Names.txt` загружаются массивы названий металлов и имён людей. Создаётся `Storage MyStorage(1000)`, с консоли читается количество действий, затем запускается цикл нужной длины. На каждом шаге случайно выбирается одно из трёх действий:
  1. удалить случайный объект из хранилища;
  2. создать новый объект случайного типа (`Metal` / `People` / `Matrix`) и поместить его в случайную позицию;
  3. взять случайный объект и, в зависимости от его реального типа (через `dynamic_cast`), либо вывести имя/параметры, либо изменить параметры, либо выполнить операции над матрицами.
