# Инженерная и компьютерная графика

Здесь собраны лабораторные работы по дисциплине **«Инженерная и компьютерная графика»**.

## Содержание

- [Лабораторная 1. WinForms и простая 2D-графика](./lab1/README.md) — первое знакомство с рисованием в Windows Forms: примитивы (линии, прямоугольники, эллипсы). Там просто нарисован домик.....
- [Лабораторная 2. Анимированный график функции (OpenTK)](./lab2/README.md) — визуализация графика математической функции в окне OpenGL с анимацией "бегающей" точки и подсветкой координат курсора.
- [Лабораторная 3. Тело вращения](./lab3/README.md) — построение 3D-модели как тела вращения по заданному профилю, вращение объекта, разные режимы отрисовки (точки/каркас/поверхность).
- [Лабораторная 4. Функциональные поверхности](./lab4/README.md) — генерация и визуализация функционально заданных 3D-поверхностей (сетка, нормали, освещение, поворот камеры).
- [Лабораторная 5. Текстурирование тела вращения](./lab5/README.md) — наложение текстуры на поверхность 3D-объекта, работа с `Bitmap`, текстурные координаты и режимы отображения (fill/line/point).

## Темы, которые покрываются

- Базовая 2D-графика в Windows Forms: рисование примитивов, работа с `Graphics`, простая анимация, сохранение и загрузка изображений.  
- OpenGL через OpenTK: инициализация контекста, система координат, матрицы проекции и моделирования, viewport.  
- 3D-геометрия: тела вращения, работа с вершинами и полигонами, треугольные ленты, аппроксимация поверхностей.  
- Нормали и освещение: численное вычисление нормалей, настройка материалов и источников света.  
- Текстурирование: загрузка текстур из BMP, настройка параметров текстуры, привязка текстурных координат к вершинам.

## Стек и инструменты

- Язык: C# (.NET).  
- Технологии: Windows Forms, OpenTK/OpenGL.  
- Инструменты: Visual Studio
- Платформа: Windows 10.
