# Лабораторная работа 2 — Анимированный график функции (OpenTK)

## Задание

Сделать Windows Forms-приложение с элементом `GLControl` (OpenTK), которое визуализирует график заданной функции и анимацию движения точки по этому графику.  
Требования:

- нарисовать координатную сетку и оси с стрелками;
- построить график функции `y = x²(x−2)²` в заданном диапазоне;
- реализовать анимацию: по графику движется красная точка, показывая изменение значения функции;
- при движении мыши рисовать линии от курсора к осям (крест), чтобы визуально считывать координаты.

## Что сделано

- **Инициализация OpenGL через OpenTK**  
  Настроен `GLControl` (`AnT`):  
  - задаётся viewport под размер элемента;
  - настраивается ортографическая проекция `GL.Ortho(...)` с учётом соотношения сторон окна;
  - рассчитываются коэффициенты `devX` и `devY` для перевода координат мыши из пикселей в координаты сцены.

- **Расчёт значений функции**  
  В методе `functionCalculation()`:
  - по шагу `0.1` заполняется массив `GrapValuesArray[300, 2]` точками графика в диапазоне `x ∈ [-15; 15]`;
  - считается `y = x * x * (x - 2) * (x - 2)`;
  - результат сохраняется в массив, количество элементов записывается в `elements_count`, флаг `not_calculate` снимается, чтобы не пересчитывать данные каждый кадр.

- **Отрисовка графика и анимации**  
  В `DrawDiagram()`:
  - при первом вызове гарантируется расчёт значений функции;
  - график рисуется как ломаная (`PrimitiveType.LineStrip`) по массиву координат;
  - поверх графика выводится красная точка (`PrimitiveType.Points`), берущая координаты из `GrapValuesArray[pointPosition, ...]`;
  - индекс `pointPosition` обновляется в таймере `PointInGrap_Tick`, что даёт эффект движения точки по кривой.

- **Сцена: сетка, оси и линии от курсора**  
  В `Draw()`:
  - очищается фон (`GL.ClearColor(Color.Bisque)` + `GL.Clear(...)`);
  - через двойной цикл выводится “ковёр” из точек, имитирующий фон-сетку;
  - рисуются оси координат с стрелками;
  - вызывается `DrawDiagram()` для построения графика;
  - по текущим координатам мыши (`AnT_MouseMove`) рассчитываются `lineX` и `lineY`, и красными линиями проводятся перпендикуляры от курсора к осям.

- **Анимация и взаимодействие**  
  Таймер `PointInGrap` с интервалом 30 мс:
  - вызывает `Draw()` примерно 30 раз в секунду;
  - сдвигает `pointPosition` по массиву точек, а при достижении конца возвращается к началу, зацикливая анимацию.  
  Обработчик `AnT_MouseMove` сохраняет координаты мыши и пересчитывает параметры линий от курсора к осям с учётом текущего масштаба сцены.

В итоге получается небольшое приложение на C# + OpenTK, которое показывает анимированный график функции в окне OpenGL: с сеткой, осями, бегущей по кривой точкой и интерактивными линиями от курсора к осям.
