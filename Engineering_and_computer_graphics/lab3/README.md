# Лабораторная работа 3 — Тело вращения (шахматный слон)

## Задание

Построить и визуализировать в OpenGL 3D-модель шахматного слона как тело вращения по заданному профилю. Реализовать вращение фигуры в окне, управление скоростью и направлением вращения, а также несколько режимов отображения (точки, каркас, закрашенная поверхность).

## Что сделано

- **Геометрия тела вращения**  
  - Профиль фигуры задан набором точек `GeometricArray` в плоскости XZ (основание, «ножка», тело, шарик, «пимпочка» на вершине).
  - Для каждой точки профиль поворачивается вокруг оси с шагом `Angle = 2 * π / Inter`, результат записывается в массив `ResaultGeometric[ax, bx, 3]`.
  - В итоге формируется сетка вершин тела вращения: `ax` — вдоль высоты слона, `bx` — по окружности.

- **Режимы визуализации** (`comboBox1`)  
  - `GL_POINTS` — простое отображение всех вершин как точек (`PrimitiveType.Points`).  
  - `GL_LINES` — каркасная модель: линии между соседними точками по высоте и по окружности (`PrimitiveType.LineStrip`).  
  - `GL_QUADS` — закрашенная оболочка из четырёхугольников (`PrimitiveType.Quads`) с расчётом нормалей через векторное произведение и включённым освещением (`DepthTest`, `Lighting`, `Light0`).

- **Камера и управление вращением**  
  - Камера отодвигается от объекта через `GL.Translate(0, 0, -20 - trackBar1.Value)`, ползунок `trackBar1` меняет дистанцию до модели.
  - Фигура непрерывно вращается вокруг двух осей, углы `rot_1` и `rot_2` инкрементируются в обработчике таймера `RenderTimer_Tick`.
  - При наведении мыши на окно с `GLControl` таймер запускается, при уходе курсора — останавливается, вращение прекращается.
  - Клик мышью по области OpenGL переключает направление вращения (меняется знак коэффициента `k`).
  - Ползунок `trackBar2` задаёт интервал таймера и фактически управляет скоростью анимации.

В итоге получается WinForms-приложение на C# + OpenTK, которое визуализирует шахматного слона как тело вращения с разными режимами отображения и управляемым вращением в 3D.
