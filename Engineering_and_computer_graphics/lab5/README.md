# Лабораторная работа 5 — Текстурирование тела вращения

## Задание

Разработать OpenGL-приложение, которое накладывает текстуру на тело вращения, построенное в лабораторной работе №3 (фигура «слон»).  
Требования: :contentReference[oaicite:0]{index=0}  

- использовать ранее реализованную геометрию тела вращения;
- загрузить изображение (BMP) и использовать его как текстуру;
- настроить параметры текстуры (масштабирование, фильтрация);
- реализовать режимы отображения: без текстуры и с текстурой;
- обеспечить вращение модели и управление скоростью/масштабом сцены.

## Что сделано

- **Геометрия тела вращения (слон)**   
  - Профиль фигуры задан в массиве `GeometricArray` (основание, ножка, тело, шарик, «пимпочка»).
  - В трёхмерную модель он превращается вращением вокруг оси: во вложенных циклах по `ax` (высота) и `bx` (угол) заполняется массив `ResultGeometric[ax, bx, 3]`.
  - Угол шага `Angle = 2π / MaxIter`, так что получается замкнутая оболочка слона из колец и меридианов.

- **Текстура и координаты**   
  - Вспомогательный класс `GLTexture` загружает `Bitmap` в OpenGL-текстуру через `LockBits` и `GL.TexImage2D` (формат BGR → RGB).
  - В `comboBox2` выбирается режим: «Без текстуры» / «Узорная плитка», при смене значения из ресурсов подгружается `image5` и передаётся в `GLTexture.LoadTexture(...)`.
  - В режиме закрашенной поверхности (`GL_QUADS`) для каждой вершины задаются текстурные координаты `GL.TexCoord2((double)bx / MaxIter, (double)ax / MaxIter)` — текстура равномерно «разворачивается» по высоте и окружности фигуры.

- **Освещение, нормали и режимы отображения** :contentReference[oaicite:3]{index=3}  
  - В `AnT_Load` включены тест глубины, освещение и источник `Light0`; используется перспектива через `GL.Frustum`.
  - В режиме `GL_QUADS` для каждого четырёхугольника вычисляется нормаль как векторное произведение рёбер, затем нормализуется и передаётся в `GL.Normal3(...)` для корректного затенения.
  - `comboBox1` переключает:
    - `GL_POINTS` — точки сетки;
    - `GL_LINES` — каркас (LineStrip);
    - `GL_QUADS` — закрашенная поверхность с освещением и (по выбору) текстурой.

- **Управление и анимация**   
  - Фигура непрерывно вращается вокруг двух осей, углы `rot_1` и `rot_2` обновляются в `RenderTimer_Tick`.
  - Клик по `GLControl` инвертирует направление вращения (`flagrotate`).
  - `trackBar1` управляет удалением камеры (`GL.Translate(0, 0, -70 + trackBar1.Value)`), `trackBar2` — интервалом таймера и скоростью анимации.
  - При наведении мыши на область рендеринга таймер запускается, при уходе — останавливается.

В итоге лабораторная работа собирает воедино геометрию тела вращения из ЛР3, освещение и расчёт нормалей из ЛР4 и добавляет полноценное текстурирование: загрузку BMP, настройку текстурных параметров и привязку текстуры к поверхности 3D-объекта.
