# Лабораторная работа 4 — Функциональная поверхность (параболический цилиндр)

## Задание

Визуализировать в OpenGL функционально заданную поверхность — параболический цилиндр вида `z = 0.1 · x²`.  
Нужно:

- сгенерировать поверхность по сетке точек в (x, y);
- посчитать нормали к поверхности;
- настроить камеру, материалы и источник света;
- сделать анимацию вращения поверхности;
- дать пользователю переключать режимы отображения: точки, каркас, закрашенная поверхность.

## Что сделано

- **Окно и рендер**  
  Приложение на WinForms с `GLControl` (`AnT`) и таймером `RenderTimer`. На каждом тике вызывается `DrawSurface()` и обновляется содержимое OpenGL-окна.

- **Материал, свет, камера**  
  В `SetupMaterial()` задаются цвет и блеск материала (diffuse/ambient/specular, shininess).  
  В `SetuplLight()` настраивается один источник света (`Light0`) с позицией и компонентами освещения.  
  В `SetupCamera()` создаётся матрица `LookAt` — камера смотрит с точки (12, 12, 8) в центр сцены, а сама поверхность плавно вращается вокруг оси Z.

- **Генерация поверхности**  
  Класс `CSinSurface` описывает поверхность:
  - функция `Sinc(x)` возвращает `0.1 * x * x` — это профиль параболического цилиндра;
  - функция `F(x, y, z) = Sinc(x) - z` задаёт поверхность в неявном виде;
  - в `CalculateVertex(x, y)` для каждой точки:
    - считается `z = Sinc(x)`;
    - численно оцениваются производные по x и y (через маленькое приращение `delta`);
    - по этим производным находится вектор нормали и нормируется;
    - возвращается структура `Vertex` с координатами (x, y, z) и нормалью (nx, ny, nz).

- **Отрисовка сетки**  
  В `DrawSurface()`:
  - задаётся диапазон по x и y (`[-10; 10]`) и количество узлов сетки (`50 × 50`);
  - по шагам `dx` и `dy` строится двумерная сетка, и для каждой пары соседних рядов создаются ленты из треугольников (`TriangleStrip`);
  - для каждой вершины отправляются в OpenGL координаты и нормаль;
  - вся геометрия записывается в дисплейный список и затем вызывается одной командой.

- **Режимы отображения**  
  Выбор в `comboBox1` переключает:
  - `GL_POINTS` — точки сетки;
  - `GL_LINES` — каркас (wireframe);
  - `GL_QUADS` — сплошная поверхность с освещением.  
  При этом включены отсечение невидимых граней (`CullFace`) и тест глубины (`DepthTest`), так что модель выглядит как нормальный 3D-объект.

В итоге это небольшое приложение на C# + OpenTK, которое генерирует параболический цилиндр по формуле, считает нормали численно и красиво крутит поверхность в трёх режимах отображения с освещением.
