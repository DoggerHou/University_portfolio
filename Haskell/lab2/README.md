# Лабораторная 2 — Символьные функции, множества и сортировка

## Задание

Цель работы — потренироваться в работе с символами, числами в разных системах счисления, кортежами, теоретико-множественными операциями и простыми сортировками в функциональном стиле.

 

- через GHCi изучить функции и операторы над символами и кодами:
  `isUpper`, `isLower`, `isAlpha`, `isDigit`, `toUpper`, `toLower`, `ord`, `chr`;  
- реализовать свои версии функций:
  `digitToInt` и `intToDigit` для цифр и шестнадцатеричных символов;
- написать преобразования:
  - `hexToDecMy :: String -> Integer` — из шестнадцатеричной записи в десятичное число;
  - `decToHexMy :: Integer -> String` — из десятичного числа в строку с 16-ричной записью;
- поработать с кортежами и парами:
  реализовать свои `zip` и `unzip`;
- реализовать теоретико-множественные операции над списками:
  `nub`, `delete`, `union`, `(\\)`, `intersect`, а также функции над «булеаном» множества;
- сделать свои сортировки и вспомогательную аналитику по строкам:
  `insert`, `sort`, `countCharsMy`;
- познакомиться с модулем `Debug.Trace` и функцией `trace` для отладки рекурсивных функций.

## Что сделано

В модуле  реализованы ключевые функции из задания.
- **Символы и системы счисления**
  - `digitToIntMy :: Char -> Int` — своя версия `digitToInt`, умеет:
    - преобразовывать `'0'..'9'` в `0..9`,
    - `'a'..'f'` / `'A'..'F'` в `10..15`,
    - на остальных символах падает с `error`.
  - `intToDigitMy :: Int -> Char` — обратное преобразование для чисел `0..15` (0–9 и `A..F`), на остальных — `error`.
  - `hexToDecMy :: String -> Int` — перевод строки с 16-ричным числом в десятичное:
    идёт по строке слева направо, разряды домножаются на `16^n`. Внутри используется вспомогательная рекурсивная функция.
  - `decToHexMy :: Int -> String` — перевод десятичного числа в 16-ричную строку:
    через деление на 16 и накопление остатка в списке символов.

- **Кортежи и пары**
  - `zipMy :: [a] -> [b] -> [(a,b)]` — своя реализация `zip` через рекурсию и сопоставление с образцом.
  - `unzipMy :: [(a,b)] -> ([a],[b])` — обратная операция: раскладывает список пар на пару списков.

- **Теоретико-множественные операции**
  - `nub :: Ord a => [a] -> [a]` — удаляет дубликаты из списка, оставляя только первые вхождения.
  - `delete :: Eq a => a -> [a] -> [a]` — удаляет первое вхождение заданного элемента.
  - `union :: Eq a => [a] -> [a] -> [a]` — объединение двух списков как множеств: к первому добавляются только те элементы второго, которых ещё нет.
  - `(\\) :: Eq a => [a] -> [a] -> [a]` — разность множеств: из первого списка убираются все элементы, которые встречаются во втором.
  - `intersect :: Eq a => [a] -> [a] -> [a]` — пересечение: оставляет только те элементы первого списка, которые есть во втором.

- **Сортировка и подсчёт частоты символов**
  - `insert :: Ord a => a -> [a] -> [a]` — вставка элемента в уже отсортированный список по возрастанию.
  - `sortMy :: Ord a => [a] -> [a]` — сортировка списка вставками: рекурсивно сортирует хвост и вставляет голову через `insert`.
  - `qsort :: Ord a => [a] -> [a]` — реализация быстрой сортировки через list comprehension: выбирает опорный элемент и разбивает список на `< x` и `>= x`.
  - `countCharsMy :: String -> [(Char, Int)]` — считает количество вхождений каждого символа в строке и возвращает список пар `(символ, частота)`, отсортированный по убыванию частоты. Для этого используется:
    - `sort` и `group` из `Data.List` для сгруппированного списка,
    - `sortBy` с кастомной функцией сравнения по второму элементу пары.

Модуль также импортирует `Debug.Trace`, так что при желании сюда можно было добавлять вызовы `trace` для отладки рекурсивных функций, но основная логика лабы сосредоточена на преобразовании чисел/строк, теоретико-множественных операциях и нескольких реализациях сортировки.
