# Лабораторная 1 — Простейшие функции в Haskell

## Задание

Цель работы — потренироваться в базовом Haskell: арифметика, логика, списки, рекурсия и сопоставление с образцом.

По методичке нужно было:

- в интерпретаторе GHCi посмотреть типы и поведение базовых арифметических функций и операторов  
  `(+), (-), (*), (/), div, mod, (^)`,  
  а затем написать свои варианты стандартных функций:
  `sum`, `product`, `max`, `min`, `maximum`, `minimum`, `even`, `odd`, `gcd`, `lcm`, `(^)`
  под другими именами;
- реализовать функции  
  `factMy :: Integer -> Integer` — факториал,  
  `fibMy :: Integer -> Integer` — число Фибоначчи по номеру, через простую рекурсию;
- в GHCi изучить логические операторы  
  `(>), (<), (==), (/=), (>=), (<=), (&&), (||), not`  
  и реализовать свои версии функций `and` и `or`;
- в GHCi посмотреть типы и поведение базовых списочных функций  
  `(:), null`, а также написать свои реализации:
  `head`, `tail`, `last`, `init`, `length`, `(!!), (++)`, `concat`,  
  `take`, `drop`, `reverse`, `elem`, `replicate`;
- реализовать дополнительные функции работы со списками:
  - `lookupMy :: Eq a => a -> b -> [(a, b)] -> b`
  - `substrMy :: [a] -> Int -> Int -> [a]`
  - `strReplaceMy :: Eq a => [a] -> [a] -> [a] -> [a]`
  - `elemIndices :: Eq a => a -> [a] -> [Int]`
  - `strPosMy :: Eq a => [a] -> [a] -> [Int]`
  - `strRotateMy :: [a] -> Int -> [a]`
  - `unevenHandWritingMy :: String -> String`.

## Что сделано

В файле лабы все функции собраны в одном модуле, реализовано следующее:

- **Числа и рекурсия**
  - Свои варианты стандартных числовых функций:
    `sumMy`, `productMy`, `maxMy`, `minMy`, `maximumMy`, `minimumMy`,
    `evenMy`, `oddMy`, `gcdMy`, `lcmMy`, `powMy`.
  - Функция `factMy` считает факториал через простую рекурсию.
  - Функция `fibMy` реализует вычисление n-го числа Фибоначчи по определению.

- **Логика**
  - Через рекурсию и сопоставление с образцом реализованы логические свёртки:
    `andMy` и `orMy` — аналоги стандартных `and` и `or` для списков `Bool`.

- **Списки**
  - Базовые операции над списками:
    свои версии `head`, `tail`, `last`, `init`, `length`, индексация `(!!)` и конкатенация.
  - Функции работы с «отрезками» списка:
    `takeMy`, `dropMy`, `reverseMy`, `elemMy`, `replicateMy` и конкатенация списка списков.

- **Строки и подсписки**
  - `lookupMy` — поиск по списку пар с запасным значением по умолчанию, если ключ не найден.
  - `substrMy` — извлечение подпоследовательности по индексам через комбинацию `take`/`drop`.
  - `strReplaceMy` — замена всех вхождений одного подсписка на другой.
  - `elemIndices` — все индексы, под которыми встречается элемент в списке.
  - `strPosMy` — все позиции вхождения подсписка в список.
  - `strRotateMy` — циклический поворот списка на заданное число шагов (перенос последних элементов в начало).
  - `unevenHandWritingMy` — преобразование строки, где каждая третья буква меняет регистр (строчная ↔ прописная).

Реализации написаны «вручную» через рекурсию и сопоставление с образцом, без использования готовых стандартных функций
