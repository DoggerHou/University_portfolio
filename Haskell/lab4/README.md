# Лабораторная 4 — Бесконечные списки, ввод-вывод и нетривиальные списковые функции

## Задание

Цель работы — научиться работать с бесконечными списками и арифметическими последовательностями в Haskell, потренироваться во вводе-выводе и реализовать набор нетривиальных функций над списками.

По заданию нужно было:

- разобраться с функциями, порождающими бесконечные списки:
  `iterate`, `repeat`, `cycle`, а также с арифметическими прогрессиями вида `[N..]` и `[N,K..]`;
- написать функции, строящие бесконечные списки:
  - псевдослучайные числа по линейному конгруэнтному методу;
  - последовательность символов, получающуюся из приписывания натуральных чисел друг за другом (`"123456789101112..."`);
  - последовательность символов для степеней десятки (`"10 100 1000..."` как строка цифр);
  - числа, у которых сумма цифр равна произведению цифр;
  - степени двойки с нечётной суммой цифр;
  - список подсписков вида `[[1,1,1,…],[2,4,8,…],[3,9,27,…],…]`;
- поработать с вводом-выводом (`putStr`, `getLine`, `readFile`, `writeFile`, `interact`) и написать несколько утилит для обработки текстовых файлов (проверка скобок, word count и т.п.);
- реализовать набор «нетривиальных» списочных функций: разбиения строк, `transpose`, группировки, `inits`/`tails`/`infixes`, проверки префикса/суффикса/подстроки, кумулятивные суммы, «численное дифференцирование» и т.д.

### Бесконечные списки

- `pseudoRandomMy :: Integer -> [Integer]` — бесконечная псевдослучайная последовательность по линейному конгруэнтному методу через `iterate`.
- `inf1 :: [Char]` — бесконечная строка цифр `"123456789101112..."` как `concatMap show [1..]`.
- `inf2 :: [Char]` — бесконечная строка цифр от степеней десятки: `concatMap show (iterate (*10) 10)`.
- `optInf1 :: [Int]` — бесконечный список чисел, у которых сумма цифр равна произведению (внутри локально определены функции суммы и произведения цифр).
- `optInf2 :: [Int]` — бесконечный список степеней двойки, у которых сумма цифр нечётная: фильтрация `iterate (*2) 2` по сумме цифр.
- `optInf3 :: [[Int]]` — список подсписков, где каждый подсписок — степени i: `[i^1, i^2, …]` для набора оснований.

### Ввод-вывод и обработка текстов

- `checkBrackets :: String -> Bool` — проверка правильной расстановки скобок с использованием стека:
  - при открывающей скобке символ кладётся в стек;
  - при закрывающей — стек сверяется на соответствующую пару;
  - в конце файл корректен, если стек пуст.
- `main` — читает файл `data.txt`, проверяет скобки и пишет в консоль сообщение `"Everything is alright."` или `"Error, False answer"`.
- `wordCount :: String -> [(String, Int)]` — считает количество вхождений каждого слова в тексте:
  - разбивает текст на слова, сортирует, группирует подряд идущие одинаковые слова и превращает группы в пары `(слово, частота)`;
  - сортирует пары по убыванию счётчика.
- `main2` — читает `input.txt`, считает `wordCount` и сохраняет результат в `output.txt`.
- `unicueWords :: String -> [(String, Int)]` — отфильтровывает пары `(слово,1)` — т.е. слова, встретившиеся ровно один раз.
- `main3` — выводит в файл список уникальных слов из входного текста.

### Нетривиальные списковые функции

- `intersperse :: a -> [a] -> [a]` — вставляет заданный элемент между всеми элементами списка.
- `explodeMy :: Eq a => a -> [a] -> [[a]]` — разбивает список на подсписки по разделителю.
- `explodeBy :: (a -> Bool) -> [a] -> [([a], [a])]` — разбивает список на чередующиеся фрагменты, где условие выполняется / не выполняется.
- `transpose :: [[a]] -> [[a]]` — транспонирование «матрицы» (списка списков).
- `groupMy :: Eq a => [a] -> [[a]]` — группировка подряд идущих одинаковых элементов.
- `initsMy :: [a] -> [[a]]` — все префиксы списка.
- `tailsMy :: [a] -> [[a]]` — все суффиксы списка.
- `infixesMy :: [a] -> [[a]]` — все непрерывные подсписки (включая пустой).
- `isPrefixOfMy`, `isSuffixOfMy`, `isInfixOfMy` — проверки префикса, суффикса и подстроки через `initsMy`/`tailsMy`/`infixesMy`.
- `cumSumPostfixMy :: Num a => [a] -> [a]` — кумулятивные суммы по всем суффиксам: `[1,2,2,4] -> [9,8,6,4]`.
- `cumSumPrefixMy :: Num a => [a] -> [a]` — кумулятивные суммы по префиксам: `[1,2,2,4] -> [1,3,5,9]`.
- `diffMy :: [Int] -> [Int]` — список разностей между соседними элементами через `zipWith (-)` и `tail`: `[1,2,2,4] -> [1,0,2]`.
- `lastFuncEver :: [Int] -> [Int]` — для каждого числа списка считает, сколько элементов строго меньше него, и возвращает список этих количеств (пример: `[1,5,3,4,3] -> [0,4,1,3,1]`).

В сумме эта лабораторная демонстрирует, как в Haskell работать с бесконечными структурами, аккуратно комбинировать ввод-вывод с чистыми функциями и строить достаточно мощные списочные утилиты поверх базовых примитивов (`map`, `filter`, генераторы списков, `zipWith`, `take`/`drop` и т.д.).
