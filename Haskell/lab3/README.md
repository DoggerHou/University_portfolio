# Лабораторная 3 — Списочные функции высших порядков

## Задание

Цель работы — попрактиковаться в использовании и написании **функций высших порядков** над списками.

По заданию нужно было:

- реализовать свои версии функций высших порядков:
  `map`, `filter`, `any`, `all`;
- через GHCi разобрать и попробовать:
  `zipWith`, композицию `(.)`, `$`, `flip`, `id`, `const`,
  `curry`, `uncurry`, `splitAt`, `takeWhile`, `dropWhile`,
  `span`, `break`, `until`, `concatMap`,
  `foldl`, `foldl1`, `scanl`, `scanl1`,
  `foldr`, `foldr1`, `scanr`, `scanr1`;
- написать несколько функций-обработчиков строк через `map`, `filter`, `elem`;
- реализовать функции, работающие сразу с *наборами функций*:
  условное применение `mapIfMy`, композицию списка функций, последовательное применение списка функций;
- реализовать аналоги `partition`, подсчёт количества выполненных предикатов, поиск индексов по условию;
- написать `sortBy` + вспомогательную функцию `on`;
- реализовать функции `filterMapAndMy` и `filterMapOrMy` для фильтрации по набору предикатов;
- написать `sumEqMy` — «сложение списков столбиком» с выравниванием;
- реализовать собственные `mapAccumL/R` и пример их применения;
- потренироваться с арифметическими последовательностями и генераторами списков, в том числе сделать функции, создающие все пары элементов списка (через генератор и без него).

## Что сделано

В модуле реализована основная часть требуемых функций.

- **Свои реализации базовых функций высшего порядка**
  - `mapMy :: (a -> b) -> [a] -> [b]` — классический `map` через рекурсию по списку.
  - `filterMy :: (a -> Bool) -> [a] -> [a]` — фильтр с охранными выражениями.
  - `anyMy :: (a -> Bool) -> [a] -> Bool` — реализован как `or . map pred`.
  - `allMy :: (a -> Bool) -> [a] -> Bool` — реализован как `and . map pred`.

- **Обработка строк и списков через `map`/`filter`**
  - `deleteVowels :: String -> String` — убирает гласные из строки через `filter` и `notElem` по набору `"eyuioaEYUIOA"`.
  - `deleteConsonants :: String -> String` — наоборот, оставляет только гласные.
  - `deleteDigits :: String -> String` — удаляет цифры `0–9` через `filter`. 
  - `getFirstsInList :: [String] -> String` — берёт первые буквы каждой строки: `map head`.
  - `getLastsInList :: [[a]] -> [a]` — берёт последние элементы подсписков: `map last`.
  - `getNthElements :: [[a]] -> Int -> [a]` — собирает N-е элементы всех подсписков: `map (!! n) listOfLists`.
  - `reverseSublists :: [[a]] -> [[a]]` — переворачивает и каждый подсписок, и сам список подсписков: `reverse (map reverse listOfLists)`. 

- **Работа с набором функций**
  - `mapIfMy :: (a -> Bool) -> (a -> b) -> (a -> b) -> [a] -> [b]` — обобщённый `map`, который для каждого элемента выбирает одну из двух функций в зависимости от предиката. 
  - `composeAllMy :: [a -> a] -> (a -> a)` — композиция списка функций (правая свёртка): пустой список даёт `id`, иначе функции навешиваются через `(.)`.
  - `applyIterateMy :: [a -> a] -> a -> a` — просто применяет результат `composeAllMy` к исходному значению.

- **Фильтрация и предикаты**
  - `partition :: (a -> Bool) -> [a] -> ([a], [a])` — разбивает список на пару списков по предикату (где `True` и где `False`), реализовано через пару `filter cond` и `filter (not . cond)`.
  - `countTruePredicate :: [a -> Bool] -> a -> Int` — считает, сколько предикатов из списка возвращают `True` на данном значении.
  - `findIndices :: (a -> Bool) -> [a] -> [Int]` — собственная реализация поиска индексов по условию через внутреннюю рекурсивную функцию с явным счётчиком индекса. 
  - `filterMapAndMy :: [a -> Bool] -> [a] -> [a]` — оставляет только те элементы, для которых **все** предикаты из списка возвращают `True` (используется `allMy`).
  - `filterMapOrMy :: [a -> Bool] -> [a] -> [a]` — оставляет элементы, для которых **хотя бы один** предикат возвращает `True` (через `anyMy`).

- **Композиция с преобразованием — `on`**
  - `on :: (b -> b -> c) -> (a -> b) -> a -> a -> c` — классическая функция `on`: сначала применяет унарную функцию к обоим аргументам, потом бинарную к результатам. Форма `f_binary \`on\` f_unary` даёт функцию вида `\x y -> f_unary x \`f_binary\` f_unary y`.

- **«Сложение столбиком» и генераторы**
  - `sumEqMy :: [[Int]] -> [Int]` — складывает набор списков «столбиком»: использует `transpose` из `Data.List`, а затем для каждой строки транспонированной матрицы берёт сумму.
  - `funcWithGenerator :: [Integer] -> [(Integer, Integer)]` — все пары `(x, y)` из списка, такие что `x < y`, с использованием генератора списков.
  - `funcWithoutGenerator :: [Integer] -> [(Integer, Integer)]` — тот же результат без генераторов: через `concatMap`, `map` и `filter (> x)`.

В сумме эта лабораторная показывает, как на Haskell работать не только с отдельными функциями и списками, но и с наборами функций, комбинировать их, строить более сложные операции (`filterMapAnd/Or`, `sumEqMy`) и аккуратно использовать list comprehension и функции из `Data.List`.
