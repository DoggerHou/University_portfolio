# Лабораторная работа 2 — TCP/IP чат

## Задание

Создать клиент-серверное приложение с GUI, работающее на localhost, позволяющее обмениваться сообщениями между клиентом и сервером на основе асинхронных TCP-сокетов. 

## Что сделано

- **Структура решения**  
  Решение состоит из трёх частей:
  - библиотека с интерфейсом сервиса, моделью пользователя и реализацией чата;
  - консольный сервер, который поднимает сервис и ждёт подключений;
  - WinForms-клиент с простым окном чата.

- **Серверная логика**  
  Сервер ведёт список подключённых пользователей (ID, имя, канал связи).  
  При подключении:
  - регистрирует нового пользователя,
  - выдаёт ему ID,
  - рассылает системное сообщение остальным.  
  При отключении — убирает пользователя из списка и тоже уведомляет остальных.  
  При отправке сообщения от клиента сервер просто пробегается по списку и пересылает текст всем подключённым.

- **Клиентское приложение**  
  Клиент — это форма с полем для имени, списком сообщений и полем ввода.  
  При подключении:
  - устанавливается связь с сервером,
  - имя блокируется, чтобы его не меняли на лету.  
  Кнопка “Отправить” шлёт текст на сервер, а все входящие сообщения сразу добавляются в список диалога. Несколько клиентов, запущенных на одной машине, видят общий чат.

В итоге лабораторная показывает базовую модель клиент–серверного приложения: отдельный процесс-сервер, несколько GUI-клиентов, общая рассылка сообщений и хранение списка активных пользователей на стороне сервера.
