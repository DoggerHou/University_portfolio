# Компьютерные сети

Здесь собраны лабораторные работы по дисциплине **«Архитектуры вычислительных систем и компьютерные сети»**.

## Содержание

- [Лабораторная 1. Диапазон IP и информация о подсети](./lab1/README.md) — WinForms-приложение, которое по введённому диапазону IP-адресов вычисляет маску подсети, адрес сети, широковещательный адрес, показывает MAC-адрес локального адаптера и для каждого IP выводит DNS-имя и статус доступности. Цель — потренироваться в работе с TCP/IP, побитовыми операциями и базовыми сетевыми API .NET.

- [Лабораторная 2. TCP/IP чат](./lab2/README.md) — клиент-серверный чат на основе асинхронных TCP-сокетов: несколько клиентов подключаются к одному хосту, отправляют сообщения и получают их по обратному вызову. Цель — разобраться с моделью клиент–сервер, контрактами WCF, callback-интерфейсом и управлением подключениями на сервере.
