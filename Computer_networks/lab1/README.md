# Лабораторная работа 1 — диапазон IP и информация о подсети

## Задание

Сделать простое GUI-приложение, которое:

- принимает от пользователя диапазон IP-адресов (первый и последний адрес);
- проверяет каждый адрес в диапазоне и выводит в таблицу:
  - сам IP-адрес,
  - DNS-имя (если есть),
  - статус доступности;
- дополнительно показывает сетевую информацию текущего компьютера:
  - маску подсети,
  - адрес сети,
  - широковещательный адрес,
  - MAC-адрес сетевого адаптера.
 
    
## Что сделано

- **Ввод диапазона IP**  
  Через два `TextBox` задаётся начальный и конечный IP-адрес. Адреса парсятся в массив байт и дальше обрабатываются в виде `byte[4]`.

- **Расчёт параметров подсети**  
  По первому и последнему IP в диапазоне через побитовые операции вычисляется:
  - маска подсети (общий префикс адресов),
  - адрес сети (`start & mask`),
  - широковещательный адрес (`start | ~mask`).  
  Результат выводится в отдельные текстовые поля.

- **Получение MAC-адреса**  
  Через `NetworkInterface.GetAllNetworkInterfaces()` выбирается первый активный адаптер (не loopback), и его физический адрес (`GetPhysicalAddress()`) выводится в поле “MAC адрес”.

- **Обход диапазона и DNS-имена**  
  Программа перебирает все IP-адреса от начального до конечного, заполняет строки в `DataGridView` и для каждого адреса:
  - формирует `IPAddress` из текущего `byte[4]`,
  - пытается получить `Dns.GetHostEntry(...)`,
  - при успехе выводит DNS-имя и статус `OK`,
  - при ошибке — плейсхолдер и статус `Not OK`.
