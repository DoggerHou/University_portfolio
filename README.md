# University_portfolio

Репозиторий с университетскими лабораторными и учебными мини-проектами: ООП, численные методы, моделирование, сетевое программирование, графика, функциональное программирование, веб и немного теорвер/статистики.

Каждый раздел — отдельный предмет. Внутри папки предмета лежит свой `README.md` с формулировкой задания и кратким описанием того, как оно выполнено.

## Как ориентироваться

1. Выбрать интересующий предмет в списке выше и перейти в соответствующую папку.
2. Открыть `README.md` внутри папки — там:
   - кратко сформулировано задание;
   - описано, что именно реализовано;
   - даны ссылки на отдельные лабораторные.
3. Внутри каждой лабораторной — свой `README` и код/проект (VS Solution, Python-скрипты, ноутбуки и т.п.).

Репозиторий задуман как **портфолио университетских работ**: это не «продакшен», а учебный код с акцентом на понимание алгоритмов, структур данных и инструментов.
