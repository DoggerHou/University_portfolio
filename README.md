# University_portfolio

Данный репозиторий содержит лабораторные работы, выполненные мною во время обучения в **бакалавриате** по специальности **МАТЕМАТИЧЕСКОЕ ОБЕСПЕЧЕНИЕ И АДМИНИСТРИРОВАНИЕ ИНФОРМАЦИОННЫХ СИСТЕМ**

Каждый раздел — отдельный предмет. Внутри папки предмета лежит свой `README.md` с формулировкой задания и кратким описанием того, как оно выполнено.

## Что здесь можно увидеть

По направлениям:

- **C# / .NET / WinForms** — ООП, сети, графика: формы, обработка событий, собственные модели и хранилища, работа с TCP/IP, OpenGL через OpenTK.
- **C++** — классическое ООП, указатели, полиморфизм, виртуальные деструкторы, свой контейнер, хранение и загрузка иерархий объектов из файла.
- **Python** — численные методы, моделирование, Монте-Карло, работа с распределениями, имитация систем, генетические алгоритмы.
- **Haskell** — функциональный стиль: рекурсия, функции высших порядков, работа со списками и строками, бесконечные структуры и простые `IO`-задачи.
- **Web / Flask** — учебный веб-сервис: шаблоны, база данных, авторизация, REST-ендпоинты и фронтенд на JS/jQuery.

## Как ориентироваться

1. Выбрать интересующий предмет в списке выше и перейти в соответствующую папку.
2. Открыть `README.md` внутри папки — там:
   - кратко сформулировано задание;
   - описано, что именно реализовано;
   - даны ссылки на отдельные лабораторные.
3. Внутри каждой лабораторной — свой `README` и код/проект (VS Solution, Python-скрипты, ноутбуки и т.п.).
