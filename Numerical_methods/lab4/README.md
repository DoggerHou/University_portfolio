# Лабораторная работа 4 — Экстраполяция Ричардсона для ряда

## Задание

Есть медленно сходящийся ряд

Z(a) = Σ i^(-a),  i = 1..∞,  при a = 1.1.

Нужно:

- посчитать частичные суммы Z(n) при n = 2, 4, 8, …;
- посчитать величину ошибки ошибки;
- применить **экстраполяцию Ричардсона** (первая и вторая экстраполяции), чтобы улучшить оценку предела;
- собрать таблицу, где видно:
  - ошибку исходной суммы;
  - ошибку после 1-й экстраполяции;
  - ошибку после 2-й экстраполяции;
  - во сколько раз экстраполяция уменьшает ошибку (отношения вида delta(1), delta(2)).

Идея: показать, что по последовательности Z(n) можно получить гораздо более точную оценку предела, а дальше увидеть, как всё ломается из-за машинного округления.

## Что сделано

В `main.py` реализован полный эксперимент.

- **Исходная последовательность**
  - Функция `Z(n)` считает частичную сумму ряда `sum_{i=1}^n i**(-a)` при `a = 1.1`.
  - Константа `zExact_CONST` — точное значение суммы, с которым сравниваемся.

- **Экстраполяция**
  - Функция `Extrapolation(z, n, k)` реализует одну ступень экстраполяции Ричардсона:
    берёт значения на шагах `n` и `n/2` и по ним строит улучшенную оценку предела с учётом порядка `k`.
  - Первая экстраполяция: применяем `Extrapolation` к Z(n) с нужным порядком.
  - Вторая экстраполяция: ещё раз применяем ту же идею уже к последовательности «экстраполированных» значений.

- **Таблица и метрики**
  - Для n = 2, 4, 8, … код считает:
    - Z(n) и ошибку `Z(n) - zExact`;
    - первую экстраполяцию и её ошибку;
    - вторую экстраполяцию и её ошибку;
    - относительные показатели:
      - `delta1` — во сколько раз изменилась ошибка после первой экстраполяции;
      - `delta2` — во сколько раз изменилась ошибка после второй.
  - Всё это выводится через `PrettyTable` в виде таблицы, готовой для отчёта.

В итоге из таблицы видно:
- как быстро падает ошибка при первой и второй экстраполяции по сравнению с исходной частичной суммой;
- и в какой момент дальнейшая экстраполяция перестаёт помогать, потому что начинают доминировать ошибки округления.
