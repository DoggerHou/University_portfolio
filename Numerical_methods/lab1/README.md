# Лабораторная работа 1 — Метод градиентного спуска

## Задание

Нужно минимизировать функцию двух переменных

f(x, y) = A * x + B * y + exp(C * x^2 + D * y^2)

методом градиентного спуска с дроблением шага.  
Коэффициенты A, B, C, D задаются по варианту (в коде прописаны два набора, активен один).  
Критерий остановки: норма градиента меньше eps, где eps = 1e-4.

## Что сделано

Реализация находится в `main.py`:

- Описана функция f(x, y) через параметры A, B, C, D.
- Вычисляются частные производные df/dx и df/dy (градиент функции).
- Реализован шаг градиентного спуска: точка обновляется как  
  `p_next = p - alpha * grad(p)`.
- Шаг alpha выбирается адаптивно:
  - если новое значение f не уменьшилось, alpha делится на 2;
  - если уменьшилось — новая точка принимается.
- Итерации продолжаются, пока длина градиента не станет меньше eps.
- На каждой успешной итерации в таблицу записываются:
  x, y, f(x, y), компоненты градиента, текущий шаг alpha и длина градиента.
- В конце программа выводит таблицу (через `PrettyTable`), найденную точку минимума и значение функции в этой точке.

Лаба показывает классический градиентный спуск с адаптивным шагом на простой двумерной функции, где параметры задаются по варианту.
