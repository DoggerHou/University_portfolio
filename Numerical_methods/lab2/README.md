# Лабораторная работа 2 — Интерполяция кубическим сплайном

## Задание

Интерполировать функцию

f(x) = sin(x)

на отрезке [0; π] кубическим сплайном и оценить погрешность интерполяции.  
По методичке: требуется построить интерполяционный сплайн третьей степени S₃(x) на равномерной сетке, решить систему для вторых производных методом прогонки (трёхдиагональная матрица) и исследовать порядок сходимости по сетке при удвоении числа узлов.

Отдельно задаются граничные условия вида

S₃''(a) = f''(a),   S₃''(b) = f''(b),

и нужно по результатам численного эксперимента подтвердить, что погрешность интерполяции убывает ~ h⁴, пока не начинает доминировать машинное округление.

## Что сделано

**Функция и её производная**

- Определена функция `f(x) = sin(x)`.
- Вторая производная `f''(x) = -sin(x)` вынесена в отдельную функцию `f_derivative_2(x)` и используется в граничных условиях.

**Построение кубического сплайна**

- Узлы: равноотстоящая сетка на [a, b] = [0.0, π].
- Для каждого числа разбиений `n` строится массив узлов `X[0..n]` и шаг `h = (b - a) / n`.
- Функция `TMA(...)` реализует метод прогонки (Thomas algorithm) для трёхдиагональной СЛАУ:
  - формируется система для вторых производных `M[i] = S₃''(x_i)` с учётом граничных условий `S₃''(a)=f''(a)` и `S₃''(b)=f''(b)`;
  - сначала вперёд считаются прогоночные коэффициенты, затем выполняется обратный ход и восстанавливается весь вектор `M[0..n]`.
- Функция `cube_spline(x, i, h, M, X)` вычисляет значение S₃(x) на отрезке `[X[i-1], X[i]]` по стандартной формуле кубического сплайна через значения `f(X[i])` и вторые производные `M[i]`.

**Оценка погрешности и порядок сходимости**

- Запускается цикл по числам разбиений `n = 5, 10, 20, …, 10240`.
- Для каждого `n`:
  - вычисляются вторые производные `M[i]` методом прогонки;
  - на каждом отрезке ошибка оценивается в средней точке `x_mid = X[i-1] + h/2` как  
    `| S₃(x_mid) - f(x_mid) |`;
  - берётся максимум по всем отрезкам → `deltaMax`.
- Дополнительно считаются:
  - `deltaOc = prevMax / 2^4` — ожидаемая погрешность при удвоении числа разбиений, если порядок действительно четвёртый;
  - `K = prevMax / deltaMax` — фактический коэффициент уменьшения погрешности при переходе от предыдущего `n` к текущему.
- Все строки вида `[n, deltaMax, deltaOc, K]` собираются в таблицу и печатаются через `PrettyTable`.

**Интерпретация**

- Для умеренных `n` коэффициент `K` получается близким к 16 → это подтверждает четвёртый порядок точности кубического сплайна на равномерной сетке.
- При очень больших `n` `K` начинает «плыть» — начинается влияние ошибок округления, как и описано в методичке.

В итоге лабораторная демонстрирует полный цикл: построение кубического сплайна по табличным значениям sin(x), решение трёхдиагональной системы методом прогонки и практическую проверку порядка сходимости по сетке.
