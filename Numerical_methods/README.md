# Методы вычислений

Здесь собраны лабораторные работы по дисциплине **«Методы вычислений»**.  
Основной упор — на практическую реализацию классических численных методов, оценку погрешности и анализ сходимости.

## Содержание

- [Лабораторная 1. Метод градиентного спуска](./lab1/README.md) — поиск минимума функции двух переменных `f(x, y) = A*x + B*y + exp(C*x^2 + D*y^2)` методом градиентного спуска с адаптивным шагом. Цель — реализовать градиент, норму, критерий останова и схему дробления шага, посмотреть, как метод уходит к минимуму при разных параметрах.

- [Лабораторная 2. Интерполяция кубическим сплайном](./lab2/README.md) — построение кубического сплайна для `sin(x)` на равномерной сетке, вычисление вторых производных методом прогонки и исследование погрешности при удвоении числа узлов. Цель — научиться собирать сплайн «по формуле», решать трёхдиагональную систему и проверять порядок метода (O(h⁴)) на практике.

- [Лабораторная 3. Численное интегрирование (метод парабол)](./lab3/README.md) — реализация формулы Симпсона, тест на функции `6*x^5` с известным точным интегралом и исследование более сложной функции `x^(1/30)*sqrt(1 + x^2)` на разных отрезках. Цель — отработать метод парабол, правило Рунге и анализ поведения погрешности при сгущении сетки.

- [Лабораторная 4. Экстраполяция Ричардсона для ряда](./lab4/README.md) — работа с частичными суммами медленно сходящегося ряда `Σ i^(-a)` при `a = 1.1`, первая и вторая экстраполяции Ричардсона и сравнение ошибок до/после. Цель — увидеть, как экстраполяция ускоряет сходимость и в каких пределах это работает.

- [Лабораторная 5. Краевая задача и метод конечных разностей](./lab5/README.md) — решение краевой задачи для линейного ОДУ второго порядка на `[0; π/4]` с известным точным решением `y(x) = sin(x)`. Используется разностная схема второго порядка и метод прогонки для трёхдиагональной системы. Цель — научиться переходить от дифференциальной задачи к разностной, решать её и оценивать погрешность по сравнению с аналитическим решением.

## Темы, которые покрываются

- Численные методы оптимизации: градиентный спуск, выбор и адаптация шага, критерии останова.  
- Интерполяция и аппроксимация: кубические сплайны, задание граничных условий, порядок точности.  
- Численное интегрирование: метод парабол (Симпсона), правило Рунге, практическая оценка порядка метода.  
- Сходимость и погрешности: анализ уменьшения ошибки при сгущении сетки, влияние машинного округления.  
- Экстраполяция Ричардсона: улучшение оценки предела последовательности и ускорение сходимости рядов.  
- Численное решение ОДУ: краевые задачи, разностные схемы, трёхдиагональные системы, метод прогонки.
