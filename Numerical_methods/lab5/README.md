# Лабораторная работа 5 — Краевая задача и метод конечных разностей

## Задание

Нужно решить краевую задачу для линейного ОДУ второго порядка на отрезке `[0; π/4]`
методом **конечных разностей** и решить получившуюся трёхдиагональную систему
**методом прогонки (Thomas algorithm)**.

Специально берётся такой пример, где точное решение известно заранее:

- точное решение: `y(x) = sin(x)`;
- коэффициенты в краевых условиях: `c1 = c2 = d1 = d2 = 1`;
- функции в уравнении подобраны так, чтобы `sin(x)` действительно удовлетворяла и самому уравнению, и краевым условиям (это позволяет считать реальную погрешность численного решения по точной формуле).

Нужно:

- построить равномерную сетку на `[0; π/4]` для разных `n` (2, 4, 8, 16, …);
- для каждой сетки решить разностную задачу методом прогонки;
- сравнить полученное численное решение с `sin(x)` в нескольких характерных точках (начало, середина, конец отрезка) и посмотреть, как падает ошибка при сгущении сетки.

## Что сделано


### 1. Постановка разностной задачи

- В коде заданы функции коэффициентов уравнения и правая часть так, чтобы точным решением была `y(x) = sin(x)`.
- Отрезок решения: `a = 0`, `b = π/4`.
- Для выбранного числа разбиений `n` строится равномерная сетка `x_0, …, x_n` и шаг `h`.

### 2. Метод конечных разностей + прогонка

- Для внутренних узлов записывается разностная схема второго порядка (вида `α_i * y_{i-1} + β_i * y_i + γ_i * y_{i+1} = φ_i`).
- Краевые условия с коэффициентами `c1 = c2 = d1 = d2 = 1` учитываются в первых и последних строках системы.
- Получается классическая трёхдиагональная СЛАУ, которая решается **методом прогонки**:
  - прямой ход — вычисление прогоночных коэффициентов;
  - обратный ход — восстановление решения `y_i` от правого края к левому.
- В результате получается массив значений `Y[i]` — численное решение в узлах сетки.

### 3. Оценка погрешности и вывод

Для каждого `n`:

- считается решение `Y` на сетке;
- вычисляются абсолютные ошибки в трёх точках:
  - в начале отрезка: `|sin(0)    − Y[0]|`;
  - в середине:       `|sin(π/8)  − Y[n/2]|`;
  - в конце:          `|sin(π/4)  − Y[n]|`;
- результаты собираются в таблицу и выводятся через `PrettyTable`:
  для каждого `n` видно, чему равны ошибки в трёх точках.

По таблице можно увидеть, как при удвоении числа узлов погрешность уменьшается
(порядок схемы) и насколько хорошо метод конечных разностей с прогонкой
восстанавливает известное точное решение `y(x) = sin(x)` на краевой задаче.
