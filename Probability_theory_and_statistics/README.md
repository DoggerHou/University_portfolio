# Лабораторная работа — Теория вероятностей и матстатистика


По условию выборка дана в виде таблицы (50 наблюдений), дальше нужно последовательно выполнить следующие шаги:

## Задание

По исходной выборке требуется:

1. Построить **вариационный ряд**
2. Построить **группированную выборку** с числом интервалов  
   \( k = 3 + \lfloor \log_2 n \rfloor \) (в условии это записано как \( k = 3 + 10 \) для конкретного n).
3. Построить **гистограмму** и **полигон частот** по сгруппированным данным.
4. По группированной выборке найти **точечные оценки**:
   - математического ожидания \( \hat{\mu} \),
   - среднеквадратического отклонения \( \hat{\sigma} \).
5. Построить **доверительные интервалы** для математического ожидания при уровнях доверия 0.95 и 0.99.
6. По виду гистограммы выбрать подходящий **закон распределения**, опираясь на пункты 2–3.
7. Найти **параметры теоретического распределения методом моментов**. На одном графике построить:
   - гистограмму,
   - полигон частот,
   - кривую плотности выбранного теоретического распределения с найденными параметрами.
8. Проверить гипотезу о том, что выборка подчиняется выбранному закону распределения, с помощью **критерия согласия \(\chi^2\)** при уровне значимости  
   \( \alpha = 0.01 \). Сделать вывод: гипотеза принимается или отвергается.

## Что сделано в ноутбуке

Решение оформлено в Jupyter Notebook

Основные шаги:

- **Ввод данных**
  - Выборка забита прямо в ноутбуке как список чисел.
  - Для удобства дальнейших расчётов используется `pandas.DataFrame`.

- **Вариационный ряд и описательная статистика**
  - Данные сортируются по возрастанию.
  - Считаются базовые характеристики: `min`, `max`, выборочное среднее, дисперсия, стандартное отклонение.

- **Группировка и частоты**
  - По формуле для \(k\) выбирается число интервалов.
  - Строятся границы интервалов и считается:
    - частота попаданий в каждый интервал,
    - относительные частоты,
    - середины интервалов.
  - Всё это складывается в таблицу (DataFrame) — удобно для отчёта.

- **Гистограмма и полигон**
  - По интервалам и частотам строится гистограмма (плотности) через `matplotlib`.
  - Отдельно рисуется полигон частот по серединам интервалов.
  - Эти графики используются дальше для сравнения с теоретическим распределением.

- **Оценки параметров и доверительные интервалы**
  - Считается выборочное среднее и выборочное стандартное отклонение на основе сгруппированных данных.
  - Для математического ожидания строятся доверительные интервалы
    при уровнях доверия 0.95 и 0.99
    (через нормальное приближение / t-распределение, в зависимости от выбранной формулы).

- **Выбор теоретического распределения и метод моментов**
  - По форме гистограммы и значениям характеристик в качестве модели выбирается **нормальное распределение**.
  - Параметры \( \mu \) и \( \sigma \) оцениваются методом моментов (по сути — выборочное среднее и выборочное СКО).
  - Строится график:
    - гистограмма относительных частот,
    - полигон,
    - поверх — теоретическая плотность нормального распределения `N(μ̂, σ̂)`.

- **Критерий согласия \(\chi^2\)**
  - Для тех же интервалов считаются **ожидаемые частоты** на основе выбранного нормального распределения.
  - Вычисляется статистика
    \[
    \chi^2 = \sum \frac{(n_i - n_i^{\text{теор}})^2}{n_i^{\text{теор}}}
    \]
    и число степеней свободы \( \nu = k - 1 - m \), где `m` — число оцениваемых параметров.
  - Через `scipy.stats.chi2` находится критическое значение \(\chi^2_{\text{crit}}\) при \(\alpha = 0.01\).
  - В ноутбуке выводится текстовый вывод вида:
    - «Гипотеза не отвергается» — если \(\chi^2 < \chi^2_{\text{crit}}\),
    - или «Гипотеза отвергается» — в противном случае.
